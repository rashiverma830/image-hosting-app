# Lumina - Image Hosting & NFT Platform 🖼️✨

Lumina is a sleek, modern, and highly interactive Image Hosting and NFT Marketplace platform. It allows creators to upload, preview, and showcase their digital art (NFTs) while offering a beautiful interface for users to browse, bid, and save their favorite creative pieces.

## 🚀 Features
- **Dashboard & Creative Hub:** Upload and manage your images and digital assets seamlessly.
- **NFT Bidding System:** Beautiful UI to browse active auctions and place bids on exclusive art.
- **Creator Profiles:** Dedicated profile pages with customizable cover photos and avatars.
- **Wallet Integration:** Dummy MetaMask integration to view balances and simulate deposits/withdrawals.
- **Live Search & Notifications:** Systematic, real-time notification drop-downs and search interfaces.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, CSS3
- **Design:** Modern Glassmorphism, CSS Variables, and Flexbox/Grid Layouts
- **Icons:** SVG-based sleek UI icons
- **State Management:** React Hooks (useState, useEffect) & LocalStorage for persistence

## 💻 Running Locally

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. **Open in Browser:**
   Visit `http://localhost:5173` to view the app!
